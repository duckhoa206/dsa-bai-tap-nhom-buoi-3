## Phụ trách và đóng góp

- **Phụ trách:** Châu Kim Huy.
- **Đóng góp:** Khoa xác nhận phần liên quan đến tích hợp.

## Cần soạn

- Mô tả run và cách trộn hai run đã sắp xếp.
- Mã giả hàm trộn và Merge Sort bottom-up.
- Ví dụ minh họa sự thay đổi của mảng qua từng `runLength`.
- Độ phức tạp thời gian `O(n log n)` và bộ nhớ phụ.
- Giải thích cách xử lý run cuối không đủ chiều dài.

Nội dung đã chốt sẽ chuyển cho Quân để đưa vào báo cáo.
