## Phụ trách và đóng góp

- **Phụ trách:** Nguyễn Hoàng Quân.
- **Đóng góp:** Huy, Thiện và Khoa cung cấp phần mô tả kỹ thuật của mình.

## Cần soạn

- Khái niệm sắp xếp nội và sắp xếp ngoại.
- Lý do dữ liệu lớn cần sắp xếp ngoại.
- Khái niệm run, tạo run ban đầu và trộn run.
- Luồng dữ liệu từ chương trình sinh đến tệp kết quả.
- Dàn ý file Word, danh sách hình/bảng và checklist gói nộp.

Mỗi số liệu thực nghiệm phải ghi nguồn từ tệp trong `ket_qua/` hoặc `ket_qua_chung/`.
