## Mục đích

Chứa file Word chính thức, hình ảnh minh họa, mã giả và tài liệu dùng để hoàn thiện báo cáo.

## Phụ trách chính

- Nguyễn Hoàng Quân phụ trách tổng hợp, định dạng và chốt báo cáo.

## Người đóng góp

- Nguyễn Hoàng Quân: lý thuyết sắp xếp ngoại và tổng hợp.
- Châu Kim Huy: ý tưởng, mã giả và phân tích Merge Sort nội.
- Nguyễn Ngọc Thiện: mô tả chương trình sinh dữ liệu.
- Phạm Đức Khoa: mô tả Merge Sort ngoại và kết quả thực nghiệm.
