# Mã nguồn chung

## Mục đích

Chứa hai chương trình hoàn chỉnh đã được tích hợp và kiểm thử:

- `Nhom06_BT03_GenerateData.cpp`: sinh tệp dữ liệu nhị phân.
- `Nhom06_BT03_MergeSort.cpp`: cài đặt Merge Sort nội và Merge Sort ngoại.

Không dùng thư mục này để lưu bản nháp cá nhân.

## Phụ trách chính

- Phạm Đức Khoa phụ trách tích hợp kỹ thuật.
- Châu Kim Huy phụ trách kiểm tra thuật toán.
- Nguyễn Hoàng Quân phụ trách xác minh bản tích hợp trước khi chốt.

## Người đóng góp

- Châu Kim Huy: Merge Sort nội và thuật toán trộn.
- Nguyễn Ngọc Thiện: chương trình sinh dữ liệu và đọc/ghi nhị phân.
- Phạm Đức Khoa: Merge Sort ngoại và tích hợp.
- Nguyễn Hoàng Quân: chạy công cụ xác minh, kiểm tra giao diện và sự thống nhất giữa mã nguồn với báo cáo.

## Quy tắc tích hợp

1. Mã nguồn được phát triển và kiểm thử trong workspace cá nhân.
2. Khoa tích hợp phần Merge Sort nội của Huy vào chương trình Merge Sort ngoại.
3. Thiện kiểm tra lại chương trình sinh dữ liệu sau khi đổi tên file nộp.
4. Quân chạy bộ test tích hợp và công cụ xác minh.
5. Chỉ hai file đã qua cả bốn bước trên mới được giữ lại tại đây.
